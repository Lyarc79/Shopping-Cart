# Shopping Cart
An e-commerce Single Page Application (SPA) built with **React**, **Vite**, and **React Router**. The app performs dynamic data fetching from `fake-store-api` to render catalog items, featuring real-time cart state management, quantity updates, and total price calculation. Includes automated component testing powered by `vitest`.
